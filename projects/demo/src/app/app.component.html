ngx-api-cache

A lightweight, dependency-free API caching solution for Angular 20+ with Signals.

✨ Features

  • ✅ Automatic caching by URL
  • ✅ Signals for data, loading, error
  • ✅ Manual refresh() and patch()
  • ✅ No third-party dependencies
